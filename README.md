# Titanic Survival Analysis — Pandas, Matplotlib & scikit-learn

## Overview
A data science pipeline that loads the Titanic dataset, explores and visualizes key survival patterns (by sex, class, and age), then trains a Random Forest classifier to predict passenger survival. Demonstrates end-to-end ML workflow with clean function separation across data loading, EDA, feature engineering, training, and evaluation.

## Technologies
Python, pandas, matplotlib, scikit-learn

## How to run
python titanic.py
